# 调试与验收顺序

1. **资产与备份**：记录铭牌、雷达型号、主控/编码器型号、系统及 ROS 版本；备份车载工作空间、启动配置和本车舵机标定值。保留原厂可运行基线。
2. **底盘基线**：确认急停和使能，架空测试轮向与转向回正，再开展受控低速测试；检查前进/倒退/左右转、控制模式及停止响应。不预设串口号、波特率或固件版本。
3. **ROS 接口**：核对 topic 类型、QoS、发布频率、单位、时间戳和 TF；验证里程计方向、距离与转角。记录断开上位机或控制消息中断后的行为，再确定超时停车方案。
4. **传感器**：逐项验证点云、IMU、时间同步和外参；雷达 IP/端口按实车配置核对。短时采集数据，原始采集文件不提交 Git。
5. **算法接入**：先用录包回放检查输入输出与耗时，再在车载平台部署；明确速度/转角限制、控制源切换、急停和回退方法。

第一阶段验收：原厂基线可复现，底盘可控可停，点云/IMU/里程计可观测，TF 和时间戳一致，启动与恢复步骤有记录。当前各项均未实车验证。
